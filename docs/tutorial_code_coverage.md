## Interpretation

- Student exercise notebooks intentionally contain unexecuted starter cells.
- Cells using `input()` are designed for manual execution and may have no saved output.
- Deliberately broken examples may be preserved as Markdown or safe diagnostic cells so a full notebook run is not interrupted.
- Python Foundations I now keeps independent exercises and fully commented solutions in separate notebooks.
- Python Foundations II keeps its independent exercises, numbered solutions, guided worked exercises, applied exercises and self-test answers in their stated files.
- All notebook files are valid JSON and use a Python 3 kernelspec.
