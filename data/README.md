# Teaching data

`monthly_service_report.csv` is a synthetic dataset created for the Copenhagen E26 course. One row is intended to represent one service category in one city and reporting month. The file deliberately contains missing, inconsistent, duplicate, non-numeric, out-of-range, and logically contradictory values for beginner data-quality exercises.

The dataset contains no real people, organisations, or operational results. It must not be presented as evidence about Copenhagen, Aalborg, or Aalborg University services.

The course design was informed by the examples and file-based exercises in Rodrigo Pérez Iragorri's Aalborg class-notes repository: https://github.com/roedorpi/TAN7_Scripting_classnotes. No file from that repository is reproduced verbatim here.
